# Maple House English — AI Story Building

**One complete planned story at a time.** An original 3D animated American-English family comedy with six recurring family characters: Dan, Maya, Nina, Leo, Ella and Max.

**Generating a 15-second clip.** Open the episode’s `VIDEO_PROMPTS.md` and copy one numbered shot. Its delivery line gives clip-local speaker windows. Let the physical action continue while the characters speak, with the last reaction carrying into the cut. The same words and times appear in the episode’s full-length `SUBTITLES.srt`. The board and panel number point to the matching composition. Upload a reviewed single frame for the shot. Keep the storyboard grid and shot badge out of the movie.

All ten stories run 20 minutes each. The current sheets contain **621 creator-approved shots** and **28 shots awaiting creator review**. The [production status](CURRENT_PRODUCTION_STATUS.md) records reviewed versions. The [open repair list](docs/qa/BLOCKED_IMAGE_REPAIRS.md) links to **151 open visual findings across 87 sheets**. The approval notes inside the original screenplays and prompts date from authoring.

**Important new format:** Every episode begins with an approximately **20-minute full animated story**: comedy, gentle drama and natural learning through entertaining conversation. **No separate English-practice slots, no documentary recap blocks, no forced repeat pauses or quiz overlays** are included in that story runtime. The creator will design and add optional practice content **after** the 20-minute story; uploads may then be 25, 30 or more minutes in total. This is not a requirement that the finished upload must be 20 minutes.

Generate a reproducible complete source-derived handoff **without images, audio or video**:

```bash
python tools/production_handoff.py --output-dir /tmp/maple-production-handoff
python tools/audit_series.py --report /tmp/series-audit.md --manifest /tmp/shot-manifest.tsv
python tools/check_root_docs.py
python tools/check_series.py
python -m unittest discover -s tests -v
```

The production handoff includes **800 shot-level JSONL specifications**, an 800-row status index, **790 adjacent-shot continuity-review pairs**, a voice-dialogue workload table, and episode-level subtitle/pacing statistics. All reference candidates, action/open/end states and script dialogue are extracted from current episode sources and validated against prompts/SRT. No motion first frame, voice performance, generated image or finished film is claimed. GitHub Actions uploads these files in its `episode-audit-and-shot-manifest` artifact.
