# Shared resources and archive

`Assets/Episode_XX/` contains the original character, environment, overlay and supporting assets moved out of each episode. Episode-specific versions are retained without deduplication to avoid losing artwork.

`Archive/` preserves the previous root-level documentation, scripts, tests, workflow configuration and other episode support files under their original relative directory layout. These are historical reference materials, not active production entry points; archived links and scripts may require adaptation before reuse. Existing subtitle files are historical and need retiming against actual dialogue before assembly.

The active episode folders contain the story, video prompts, storyboard gallery and storyboard assets. All existing storyboard artwork remains unchanged.
